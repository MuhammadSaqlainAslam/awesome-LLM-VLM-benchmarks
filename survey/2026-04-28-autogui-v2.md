# AutoGUI-v2: A Comprehensive Multi-Modal GUI Functionality Understanding Benchmark (2026)

## Problem
GUI agents that autonomously interact with software interfaces must understand not only the visual appearance of UI elements but also their functional semantics — what clicking a button does, how states change, and what interaction sequences achieve a goal. Existing GUI benchmarks focus on grounding (finding UI elements) rather than functionality understanding (predicting interaction outcomes and dynamic state changes). No benchmark had comprehensively evaluated this functional understanding across multiple operating systems and platforms.

## Method
**AutoGUI-v2** (arXiv: 2604.24441, April 28, 2026) introduces a comprehensive benchmark for evaluating vision-language models' ability to understand GUI functionality and predict interaction outcomes. A VLM-human collaborative pipeline recursively parses multi-platform screenshots into hierarchical functional regions to generate evaluation tasks. The benchmark covers 2,753 tasks across six operating systems, testing models on region-level and element-level functional semantics, grounding accuracy, and dynamic state prediction.

## Benchmarks / Datasets
- 2,753 tasks across six operating systems (multi-platform coverage)
- VLM-human collaborative pipeline for hierarchical functional region annotation
- Three evaluation levels: region semantics, element semantics, dynamic state prediction
- Tests include grounding accuracy and interaction outcome prediction
- Models evaluated include Qwen3-VL, Gemini-2.5-Pro-Thinking, and other open-source/commercial VLMs

## Key Results

| Evaluation Dimension | Key Finding |
|---|---|
| Functional grounding | Open-source agent-tuned models excel |
| Functionality captioning | Commercial models dominate |
| Complex interaction logic (uncommon actions) | All models struggle significantly |
| Dynamic state prediction | Major gap across all model categories |
| Cross-OS generalization | Significant performance variance by platform |

- **All tested models — open-source and commercial — struggle with complex interaction logic for uncommon GUI actions, revealing that deep GUI comprehension remains unsolved**
- A performance split emerges: open-source models fine-tuned on agent data lead on functional grounding, while commercial models dominate on functionality captioning — no single model excels at both
- Dynamic state prediction (understanding how UI state changes after an interaction) is a critical bottleneck for all current VLMs
- The hierarchical functional region annotation pipeline provides a scalable methodology for generating GUI evaluation data across platforms

## FoxBrain Relevance
Foxconn's FoxBrain GUI agents are deployed for enterprise software automation — navigating ERP systems, MES dashboards, procurement portals, and quality management interfaces across Windows, web, and mobile platforms. AutoGUI-v2 directly benchmarks the core capability these agents require: understanding what GUI elements do, not just where they are. The finding that all models fail on uncommon or complex interaction sequences is critical for FoxBrain deployment planning — any GUI automation involving non-standard workflows must be treated as high-risk and require explicit human validation rather than autonomous execution.
