# RSRCC: A Remote Sensing Regional Change Comprehension Benchmark (2026)

## Problem
Existing remote sensing change detection benchmarks focus on identifying where changes occurred in satellite imagery, but do not assess whether models can semantically reason about what changed and explain it in natural language. This semantic gap leaves VLMs uncharacterised for the fine-grained change comprehension capabilities needed in real-world geospatial monitoring applications such as urban development tracking, disaster response, and agricultural surveillance.

## Method
**RSRCC** (arXiv: 2604.20623, April 23, 2026) is the first remote sensing change question-answering benchmark designed explicitly for fine-grained semantic reasoning about localised changes in bi-temporal satellite imagery. It was constructed via a hierarchical semi-supervised pipeline that uses Best-of-N ranking to resolve annotation ambiguity, combined with retrieval-augmented vision-language curation to ensure semantic richness. The benchmark comprises 126,000 QA pairs targeting specific regional changes requiring detailed natural-language explanation, split across training, validation, and test sets.

## Benchmarks / Datasets
- 126,000 QA pairs (87,000 train / 17,100 validation / 22,000 test)
- Bi-temporal satellite image pairs covering diverse geographic regions and change types
- Tasks require fine-grained semantic reasoning about localised regional changes in natural language
- Construction: hierarchical semi-supervised pipeline + Best-of-N ranking + retrieval-augmented curation
- Dataset available on Hugging Face

## Key Results

| Evaluation Aspect | Key Finding |
|---|---|
| Semantic change QA | First benchmark in this class; no prior baseline |
| Fine-grained regional reasoning | Current VLMs struggle with localized change description |
| Dataset scale | 126,000 QA pairs, largest semantic change QA benchmark |
| Construction quality | Best-of-N ranking resolves annotation ambiguity systematically |

- **RSRCC is the first benchmark to evaluate VLMs on semantically explaining what changed in regional satellite imagery — prior work only addressed where, not what**
- The 126,000-pair scale, with both training and test splits, enables fair comparison across supervised and zero-shot VLM approaches
- Best-of-N ranking in the construction pipeline demonstrably reduces annotation noise compared to single-annotator pipelines
- Results reveal that current VLMs capable of scene-level description struggle significantly with localised, fine-grained change reasoning in bi-temporal satellite pairs

## Enterprise / Industry Relevance
Foxconn operates global manufacturing campuses where aerial and satellite monitoring tracks construction progress, campus security perimeter changes, and logistics flow on factory grounds. RSRCC directly assesses whether VLMs can semantically describe changes between time-separated satellite images — precisely the capability needed for Foxconn's campus monitoring and site-change audit workflows. Beyond internal use, Foxconn's electronics and smart city subsidiaries provide geospatial monitoring solutions; a FoxBrain model that scores well on RSRCC would be deployable for automated change-report generation from satellite feeds. The benchmark's Hugging Face availability makes it straightforward to fine-tune and evaluate FoxBrain on the task.
