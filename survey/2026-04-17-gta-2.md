# GTA-2: Benchmarking General Tool Agents from Atomic Tool-Use to Open-Ended Workflows (2026)

## Problem
Current tool-use benchmarks rely on artificial queries and dummy tools that fail to reflect real-world agent deployment conditions. More critically, no prior benchmark measures the critical divide between atomic (single-step) tool use and open-ended multi-step workflows, leaving practitioners with no principled way to understand where agent capability breaks down as task complexity scales. Frontier models are routinely overestimated on tool use by benchmarks that avoid the coordination challenges present in real workflows.

## Method
**GTA-2** (arXiv: 2604.15715, April 17, 2026) introduces a hierarchical two-tier benchmark: GTA-Atomic tests short-horizon, single-tool tasks with realistic tools and natural queries, while GTA-Workflow tests complex, long-horizon multi-step tasks requiring coordinated tool use. The benchmark uses real executable tools and authentic task descriptions. Multiple frontier models were evaluated, and the paper studies how execution framework design (beyond model capacity) affects workflow performance. Top models achieved only 14.39% success on workflow tasks.

Authors: Jize Wang, Xuanxuan Liu, Yining Li, Songyang Zhang, Yijun Wang, Zifei Shan, Xinyi Le, Cailian Chen, Xinping Guan, Dacheng Tao

## Benchmarks / Datasets
- GTA-Atomic: short-horizon single-tool tasks with real tools and natural language queries
- GTA-Workflow: complex long-horizon multi-step tasks requiring coordinated tool orchestration
- Multiple frontier models evaluated including GPT-5.4, Gemini 3.1 Pro, Claude
- Key metrics: task success rate (atomic), workflow completion rate, execution framework comparison

## Key Results

| Tier | Top Model Success Rate | Notes |
|---|---|---|
| GTA-Atomic | < 50% | Frontier models already struggle |
| GTA-Workflow | 14.39% | Near-total failure on workflows |

- **Frontier models achieve below 50% on atomic tool tasks and only 14.39% on open-ended workflows — a dramatic capability cliff as complexity scales.**
- Execution framework design has a significant impact on workflow performance independent of model capacity, suggesting agent scaffolding is a critical engineering variable.
- Models that rank high on atomic tasks do not maintain their relative rankings on workflow tasks, indicating atomic performance does not predict workflow readiness.

## FoxBrain Relevance
Foxconn's enterprise automation vision relies on FoxBrain orchestrating multi-step tool workflows — from querying ERP systems to generating purchase orders, validating supplier data, and logging results. GTA-2's workflow tier directly mirrors these real manufacturing agentic pipelines. The 14.39% workflow success rate finding is a critical benchmark for setting realistic expectations: any FoxBrain agentic deployment should be validated against GTA-Workflow-equivalent complexity before going live. The finding that execution framework matters as much as model quality suggests that Foxconn's agent scaffolding and tool-calling infrastructure deserve equal investment alongside model selection. Running FoxBrain through GTA-2's atomic and workflow tiers would establish a clear readiness threshold for multi-tool manufacturing automation.
