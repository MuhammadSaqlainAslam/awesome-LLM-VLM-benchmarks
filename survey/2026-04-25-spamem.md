# SpaMEM: Benchmarking Dynamic Spatial Reasoning via Perception-Memory Integration in Embodied Environments (2026)

## Problem
Vision-language models are increasingly used in embodied settings — robots, autonomous systems, and interactive agents — where the environment changes dynamically and models must maintain accurate spatial beliefs over time. While VLMs perform adequately on static spatial tasks, their ability to update and preserve coherent spatial representations across long interaction sequences has never been systematically evaluated. Existing benchmarks do not capture this dynamic perception-memory integration challenge.

## Method
**SpaMEM** (arXiv: 2604.22409, April 25, 2026) is a diagnostic benchmark for evaluating how multimodal language models maintain spatial beliefs in embodied environments where scenes change dynamically. It provides 10,601,392 high-fidelity images across four modalities (RGB, depth, instance segmentation, semantic segmentation) from 25,000+ interaction sequences across 1,000 procedurally generated houses. The benchmark uses a three-level hierarchical evaluation covering atomic perception, temporal reasoning with text support, and end-to-end visual belief maintenance — 15 diagnostic tasks in total with both short-term (step-wise) and long-term (episodic) reconstruction metrics.

## Benchmarks / Datasets
- 10,601,392 high-fidelity images across RGB, depth, instance, and semantic segmentation
- 25,000+ interaction sequences in 1,000 procedurally generated houses
- Three-level hierarchical evaluation: atomic perception → temporal reasoning (text) → end-to-end visual belief maintenance
- 15 diagnostic tasks measuring spatial reasoning under dynamic scene change
- Short-term (step-wise) and long-term (episodic) reconstruction metrics

## Key Results

| Evaluation Level | Key Finding |
|---|---|
| Atomic perception (static) | Models perform adequately |
| Temporal reasoning (text-supported) | Acceptable performance with symbolic scaffolding |
| End-to-end visual belief maintenance | Performance collapse without text support |
| Coordinate grounding | Consistently difficult across all models |
| Long interaction sequences | Coherence breaks down — spatial beliefs degrade |

- **Models exhibit a consistent stacked bottleneck: performance collapses when transitioning from text-supported temporal reasoning to pure visual memory — models depend on symbolic scaffolding rather than robust spatial understanding**
- Coordinate grounding remains consistently difficult across all tested VLM families
- Spatial belief coherence degrades over long interaction sequences, exposing a fundamental limitation for embodied deployment
- The benchmark reveals that VLMs' apparent spatial competence on static tasks does not transfer to dynamic, memory-intensive embodied scenarios

## FoxBrain Relevance
Foxconn is actively developing embodied AI applications for factory floor robotics, autonomous inspection, and smart manufacturing assistants that must navigate and reason about dynamic physical environments. SpaMEM directly measures whether VLMs powering these systems can maintain accurate spatial beliefs as the environment changes — essential for safe robot navigation, object tracking, and anomaly detection across production lines. The benchmark's finding that performance collapses without text scaffolding means FoxBrain-powered embodied agents must be equipped with explicit spatial memory modules and symbolic environment representations, not just vision-only perception.
