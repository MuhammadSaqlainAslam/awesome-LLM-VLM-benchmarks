# ReVSI: Rebuilding Visual Spatial Intelligence Evaluation for Accurate Assessment of VLM 3D Reasoning (2026)

## Problem
Existing benchmarks for evaluating VLM 3D spatial reasoning contain systematic flaws: annotation artifacts from 3D reconstruction pipelines produce invalid question-answer pairs, and benchmarks assume full-scene frame access while VLMs in practice operate on sparse frame samples. These flaws cause prior evaluations to both over- and under-estimate model capability depending on the task, obscuring the true state of VLM spatial intelligence and making benchmark results unreliable for deployment decisions.

## Method
**ReVSI** (arXiv: 2604.24300, April 28, 2026) rebuilds 3D spatial reasoning evaluation from the ground up with corrected data quality and realistic input assumptions. It re-annotates 381 scenes sourced from 5 existing datasets using professional annotators, removes invalid QA pairs caused by reconstruction artifacts, and introduces frame-budget variants (16/32/64/all frames) that reflect real VLM operating conditions. Object visibility metadata tracks which objects are actually visible in each frame budget, enabling geometry-dependent accuracy measurement.

## Benchmarks / Datasets
- 381 scenes from 5 existing 3D reasoning datasets, professionally re-annotated
- Invalid QA pairs removed (caused by 3D reconstruction artifacts)
- Frame-budget variants: 16 / 32 / 64 / all frames
- Object visibility metadata per frame budget
- Geometry-dependent accuracy measures
- General and domain-specific VLMs evaluated

## Key Results

| Evaluation Dimension | Key Finding |
|---|---|
| Prior benchmark validity | Invalid QA pairs due to reconstruction artifacts — results unreliable |
| Full-frame vs. sparse-frame performance | Significant gap when realistic frame budgets applied |
| Systematic failure modes | Obscured by prior benchmarks; revealed under ReVSI |
| Controlled re-annotation | Uncovers true capability distribution across VLM families |

- **Prior 3D spatial reasoning benchmarks contain invalid question-answer pairs from reconstruction artifacts — published results on these benchmarks are unreliable for comparing model capability**
- Realistic frame-budget constraints (models see 16–64 frames, not the full scene) substantially change the performance landscape, exposing fragility hidden by full-scene evaluation
- Professional re-annotation uncovers systematic failure modes that were obscured by flawed benchmark data
- ReVSI provides the first reliable controlled evaluation framework for VLM 3D spatial reasoning under real operating conditions

## Enterprise / Industry Relevance
Foxconn is deploying VLMs for 3D spatial reasoning tasks including factory floor layout understanding, robot navigation, bin-picking, and quality inspection of 3D assemblies. ReVSI's finding that prior 3D reasoning benchmarks are systematically flawed means FoxBrain's spatial reasoning capability may have been mis-estimated using existing benchmarks. The frame-budget variants are particularly relevant to Foxconn's real-time inspection systems that process sparse video streams rather than full-scene point clouds. ReVSI provides the corrected evaluation methodology FoxBrain's vision team should use before deploying spatial reasoning in production.
