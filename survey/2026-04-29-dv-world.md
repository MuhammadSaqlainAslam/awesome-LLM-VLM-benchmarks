# DV-World: Benchmarking Data Visualization Agents in Real-World Scenarios (2026)

## Problem
Data visualization is a core enterprise task, yet no benchmark existed for evaluating AI agents on end-to-end visualization workflows under real-world complexity — ambiguous user intent, cross-platform data, and multi-step dashboard creation. Existing code generation benchmarks treat visualization as a simple chart-plotting task, missing the professional complexity of adapting visuals to evolving data, aligning outputs with stakeholder intent, and maintaining consistency across platform migrations.

## Method
**DV-World** (arXiv: 2604.25914, April 29, 2026) introduces a benchmark of 260 tasks spanning three professional visualization workflows: spreadsheet manipulation with chart and dashboard creation, visual artifact adaptation to new data, and intent alignment validated through user simulation. Tasks are sourced from real-world professional scenarios. Evaluation uses two complementary metrics — Table-value Alignment for numerical precision and MLLM-as-a-Judge with rubrics for semantic-visual quality.

## Benchmarks / Datasets
- 260 tasks across three professional visualization workflow types
- Workflow 1: Spreadsheet manipulation + chart/dashboard creation
- Workflow 2: Visual artifact adaptation to new data
- Workflow 3: Intent alignment with user simulation
- Two evaluation metrics: Table-value Alignment + MLLM-as-a-Judge with rubrics
- Tasks sourced from real-world professional scenarios

## Key Results

| Evaluation Dimension | Key Finding |
|---|---|
| Overall SOTA performance | Below 50% — all state-of-the-art models fail more than half the tasks |
| Native environmental grounding | Critical deficiency across models |
| Cross-platform evolution | Significant failure point |
| Ambiguous real-world requirements | Models struggle to resolve underspecified intent |
| Intent alignment | Substantial gap between model output and user expectation |

- **State-of-the-art models achieve less than 50% overall performance on real-world visualization tasks — existing approaches are not enterprise-grade**
- Three distinct failure modes identified: inability to ground in native environments, failure on cross-platform data evolution, and poor resolution of ambiguous requirements
- The gap between clean benchmark performance and real-world visualization tasks reveals that current agents are prototype-level tools, not production-ready systems
- MLLM-as-a-Judge with rubrics provides a scalable evaluation methodology for subjective visual quality alongside numerical precision metrics

## Enterprise / Industry Relevance
Foxconn generates large volumes of production data, quality metrics, and supply chain analytics that require visualization for management reporting, KPI dashboards, and executive briefings. DV-World's finding that all SOTA agents fail more than half of real-world visualization tasks is a direct warning for FoxBrain-powered data visualization automation: the current generation of agents cannot reliably produce enterprise-grade charts and dashboards without human oversight. The benchmark's three failure modes — environmental grounding, cross-platform adaptation, and intent resolution — map directly to the challenges FoxBrain faces when generating visualizations from heterogeneous Foxconn data systems.
