# From Recall to Forgetting: Benchmarking Long-Term Memory for Personalized Agents (2026)

## Problem
Personalised AI agents that engage with users over weeks or months must manage evolving, sometimes contradictory information — yet existing memory benchmarks evaluate only short-term recall within single sessions. No benchmark had assessed whether agents can handle obsolete or invalidated memories accumulated over extended real-world interaction timespans, leaving a critical gap in evaluating long-term personalisation quality.

## Method
**Memora** (arXiv: 2604.20006, April 21, 2026) is a long-term memory benchmark spanning weeks to months of realistic user conversations. It evaluates agents on three memory-grounded tasks — Remembering, Reasoning, and Recommending — and introduces **Forgetting-Aware Memory Accuracy (FAMA)**, a novel metric that penalises reliance on obsolete or invalidated memories. The benchmark employs automated memory-grounding checks and human evaluation to ensure data quality. Accepted to ACL 2026 Findings.

Authors: Md Nayem Uddin, Kumar Shubham, Eduardo Blanco, Chitta Baral, Gengyu Wang

## Benchmarks / Datasets
- Weeks-to-months conversation histories simulating real-world user interactions
- Three task categories: Remembering, Reasoning, Recommending
- Four LLMs and six memory agents evaluated
- Novel FAMA metric penalises use of outdated/invalidated memories
- Automated grounding checks plus human evaluation for quality assurance

## Key Results

| System Type | Memory Quality |
|---|---|
| Baseline LLMs | Frequent reuse of invalid memories |
| Memory agents | Only marginal improvements over LLM baselines |
| All evaluated systems | Failures to reconcile evolving information |

- **All evaluated memory agents show only marginal improvements over baseline LLMs on long-term memory tasks, revealing that current architectures cannot reliably manage evolving information**
- Models frequently reuse invalid or outdated memories, with no system achieving reliable obsolescence detection
- FAMA metric reveals failure modes invisible to standard accuracy metrics that reward correct recall regardless of memory validity

## Enterprise / Industry Relevance
Foxconn's enterprise FoxBrain assistant interacts with employees, supply-chain partners, and production managers over extended periods — accumulating context about ongoing projects, component specifications, and personnel preferences. Memora's FAMA metric is directly applicable to evaluating whether FoxBrain can correctly discard superseded information (e.g., outdated component prices or revised production schedules) rather than serving stale responses. The benchmark's Recommending task mirrors FoxBrain's use case in vendor recommendation and procurement advisory, where recommendations based on obsolete supplier data could cause costly procurement errors. Tracking Memora performance guides the FoxBrain team in designing memory update and invalidation protocols for long-running enterprise deployments.
