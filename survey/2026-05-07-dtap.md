# DTap: A Controllable and Interactive Red-Teaming Platform for AI Agents (2026)

## Problem
As autonomous AI agents are deployed in high-stakes domains — executing file operations, making payments, sending messages, calling APIs — they become targets for adversarial manipulation that can cause catastrophic real-world consequences: API credential leaks, unauthorised transactions, data deletion, and privacy violations. Existing agent safety evaluations use static benchmarks that cannot reproduce the dynamic, multi-step attack patterns of real adversarial conditions. No controllable, reproducible red-teaming platform existed to systematically stress-test agent systems across realistic enterprise environments at scale.

## Method
**DTap** (DecodingTrust-Agent Platform; arXiv: 2605.04808, May 2026) introduces a red-teaming platform comprising:
- **14 real-world domains** (including Google Workspace, PayPal, Slack replicas) with **50+ simulation environments**
- **DTap-Red**: an autonomous red-teaming agent that explores five injection vectors — prompt, tool, skill, environment, and combinations
- **DTap-Bench**: a curated dataset of adversarial attack scenarios with automated outcome validation (verifiable ground truth)
- Coverage of multiple security policies and risk categories across attack strategies
- 279-page comprehensive documentation with 148 figures

## Benchmarks / Datasets
- 14 real-world domain replicas (Google Workspace, PayPal, Slack, etc.)
- 50+ simulation environments
- 5 injection vector types: prompt / tool / skill / environment / combined
- DTap-Bench: curated adversarial dataset with automated verification
- Controllable attack parameterisation across risk categories and security policies

## Key Results

| Feature | Specification |

| Domains covered | 14 real-world enterprise domains |

- **First controllable, reproducible red-teaming platform for AI agents simulating realistic enterprise attack conditions across 14 domains and 5 injection vector types**
- DTap-Red autonomous red-teaming agent actively discovers new attack vectors rather than relying on pre-specified adversarial prompts — dynamic adversarial exploration
- Combined injection vectors (e.g., simultaneous prompt + tool manipulation) are the most dangerous and least studied attack class — DTap is the first platform to evaluate these systematically
- Automated outcome validation enables large-scale, reproducible red-teaming without human reviewers for each attack attempt

## Enterprise / Industry Relevance
FoxBrain's agentic deployments that interact with enterprise systems — Foxconn's ERP (SAP), collaboration tools, supplier portals, and payment workflows — are directly exposed to the attack classes DTap systematically tests. A FoxBrain agent with tool access to supplier payment systems or contract databases represents a high-value adversarial target. DTap's five injection vector taxonomy (prompt, tool, skill, environment, combined) maps directly onto FoxBrain's agentic surface: prompt injection via supplier-submitted documents, tool manipulation via crafted API responses, and environment-level attacks through poisoned database records. FoxBrain's agent security team should use DTap's methodology to red-team each agentic workflow before production deployment — particularly any workflow with payment, data access, or external API permissions — using the combined injection vector scenarios as the highest-priority attack surface.
