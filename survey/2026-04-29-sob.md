# SOB: The Structured Output Benchmark — Multi-Source Evaluation of Structured Output Quality in LLMs (2026)

## Problem
Enterprise AI workflows depend on LLMs extracting structured data (JSON, tables, schemas) from text, images, and audio. While models achieve near-perfect schema compliance — producing validly formatted outputs — the actual accuracy of extracted values is far lower and poorly understood. No benchmark had simultaneously evaluated structured output quality across all three input modalities at scale, leaving a critical blind spot for enterprise data pipelines that assume LLM-extracted values are reliable.

## Method
**SOB** (arXiv: 2604.25359, April 29, 2026) introduces a comprehensive benchmark evaluating LLM structured data extraction across text, image, and audio modalities using JSON outputs. The benchmark draws from a 25,091-record text corpus (5,000 evaluated), 209 image records from OCR-processed PDFs, and 115 audio records from the AMI corpus. Twenty-one frontier and open-weight models are evaluated across seven metrics including schema compliance and Value Accuracy (exact leaf-value match). Context length degradation is also measured.

## Benchmarks / Datasets
- Text: 5,000 evaluation records from 25,091-record corpus
- Image: 209 records from OCR-processed PDFs
- Audio: 115 records from AMI corpus
- 21 frontier and open-weight models evaluated
- 7 evaluation metrics including schema compliance and Value Accuracy
- Context length degradation analysis across all modalities

## Key Results

| Modality | Best Value Accuracy | Schema Compliance |
|---|---|---|
| Text | 83.0% | Near-perfect |
| Image | 67.2% | Near-perfect |
| Audio | 23.7% | Near-perfect |

- **Near-perfect schema compliance masks deeply unreliable value extraction: best accuracy is 83% on text, 67% on images, and only 23.7% on audio — models produce correctly formatted but wrong content**
- Performance degrades significantly with longer context across all three modalities — structured extraction reliability drops as document length increases
- Audio modality structured extraction is severely inadequate at 23.7% — LLMs cannot be trusted to extract structured data from spoken content
- The compliance-accuracy gap is a critical enterprise risk: pipelines that validate JSON schema will incorrectly pass outputs with wrong extracted values

## FoxBrain Relevance
Foxconn's data pipelines rely on structured extraction from diverse sources — typed reports (text), scanned engineering documents and invoices (image/OCR), and meeting recordings or voice notes (audio). SOB's finding that schema compliance is near-perfect while value accuracy is 83%/67%/23.7% across modalities is a direct warning: FoxBrain's structured extraction outputs may appear correctly formatted while containing wrong field values that propagate silently through downstream systems. The audio result (23.7%) means FoxBrain must not be used to extract structured data from spoken content without comprehensive human verification. Context length degradation also means long Foxconn documents need chunking strategies before structured extraction.
