# Do Agents Dream of Root Shells? Partial-Credit Evaluation of LLM Agents in Capture The Flag Challenges (2026)

## Problem
Evaluating LLM agents on cybersecurity tasks has largely relied on binary pass/fail scoring that provides no signal about partially completed exploits, making it impossible to measure incremental progress or diagnose where agents fail. Existing benchmarks use simplified synthetic environments that do not reflect realistic multi-step exploitation requiring unconventional discovery methods, privilege escalation, and strategic planning across isolated virtual machines.

## Method
**DeepRed** (arXiv: 2604.19354, April 21, 2026) is an open-source evaluation framework that places LLM agents inside isolated virtual machine environments with terminal access and measures performance through checkpoint-based partial-credit scoring. Each of the 10 CTF challenges has checkpoints derived from public writeups, allowing fine-grained measurement of how far agents progress through realistic attack chains without requiring full exploitation success.

Authors: Ali Al-Kaswan, Maksim Plotnikov, Maxim Hájek, Roland Vízner, Arie van Deursen, Maliheh Izadi

## Benchmarks / Datasets
- 10 VM-based Capture The Flag challenges spanning diverse attack categories
- Checkpoint-based partial scoring derived from public writeups
- Isolated virtual environments with full terminal access
- 10 commercially accessible LLMs evaluated

## Key Results

| Metric | Best Model Result |
|---|---|
| Avg Checkpoint Completion | 35% |
| Full Challenge Completion | Very low (below checkpoint avg) |
| Weakest Category | Unconventional discovery / extended planning tasks |

- **The best-performing model achieves only 35% average checkpoint completion, indicating fundamental gaps in multi-step offensive reasoning**
- Agents perform strongest on common challenge types (e.g., straightforward web vulnerabilities) but collapse on tasks requiring non-standard discovery techniques
- Extended strategic planning across multiple exploitation stages is the primary failure mode, even for frontier models

## FoxBrain Relevance
Foxconn's global network of manufacturing facilities requires proactive red-team simulation to identify vulnerabilities in OT/IT infrastructure before adversaries do. FoxBrain could serve as an automated penetration testing assistant to reduce the cost of routine security assessments across Foxconn's supply chain partners and factory networks. The DeepRed partial-credit framework is particularly valuable for Foxconn because it enables incremental capability assessment — allowing the security team to identify which exploitation stages FoxBrain can automate today versus where human expert oversight remains essential. The benchmark's focus on realistic VM-based environments mirrors the networked Windows and Linux systems common in Foxconn's production lines.
