# KWBench: Measuring Unprompted Problem Recognition in Knowledge Work (2026)

## Problem
Most LLM benchmarks present models with explicitly framed problems — the challenge is already named and the solving method implied. Real knowledge work, however, requires first recognizing which type of problem a situation represents before any solution is attempted. This upstream "unprompted problem recognition" capability has never been measured: existing evaluations test whether models can solve problems, not whether they can identify them from raw situational inputs.

## Method
**KWBench** (arXiv: 2604.15760, April 17, 2026) comprises 223 tasks sourced from business professionals across domains including mergers and acquisitions, contract analysis, pharmacy, and fraud investigation. Each task embeds a game-theoretic or decision-theoretic pattern into raw situational descriptions without explicitly naming the problem type. Models must produce an unprompted recognition of the governing structure. Expert annotations identify the correct problem type and predicted failure modes. Sixteen models were evaluated.

Authors: Ankit Maloo

## Benchmarks / Datasets
- 223 expert-curated tasks from real professional knowledge-work scenarios
- Domains: M&A, contract analysis, pharmacy, fraud, and others
- 16 LLMs evaluated across the benchmark
- Key metrics: problem recognition accuracy, top-k model routing coverage, inter-model agreement rate

## Key Results

| Setting | Best Single Model | 8-Model Ensemble |
|---|---|---|
| Problem Recognition Accuracy | 27.9% | 50.7% |
| Inter-model Agreement (top-2) | 31.7% | N/A |

- **The best single model correctly recognizes the governing problem structure in only 27.9% of tasks — reflecting a large gap between knowing concepts and applying them unprompted.**
- Routing across the eight best models doubles coverage to 50.7%, suggesting ensembling is currently the only viable path to acceptable performance.
- Models can articulate the relevant game-theoretic or decision-theoretic concepts when explicitly prompted, confirming the gap lies in recognition, not knowledge retrieval.

## Enterprise / Industry Relevance
In enterprise manufacturing and supply-chain contexts, FoxBrain is often presented with raw operational logs, procurement anomalies, or process deviations where the first task is recognizing what type of problem exists — a bottleneck, a fraud signal, a scheduling conflict — before initiating any resolution workflow. KWBench directly quantifies this unprompted pattern-recognition capability. A FoxBrain deployment scoring below 30% on KWBench tasks would be unreliable in autonomous diagnostic workflows where operators provide raw observations rather than pre-framed queries. Evaluating FoxBrain on KWBench-style scenarios from manufacturing domains (production scheduling, supplier risk, QC anomalies) would establish a recognition baseline before any agentic task routing is enabled.
