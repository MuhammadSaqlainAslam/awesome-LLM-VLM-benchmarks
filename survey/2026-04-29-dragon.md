# DRAGON: A Benchmark for Evidence-Grounded Visual Reasoning over Diagrams (2026)

## Problem
Vision-language models frequently achieve high accuracy on diagram question answering tasks, yet it is unclear whether they are genuinely reasoning from visual evidence or exploiting spurious correlations and text shortcuts. Existing diagram benchmarks measure answer correctness but not whether models correctly localise the specific diagram regions that support their answers — a critical gap for interpretability and reliability in scientific, technical, and educational applications.

## Method
**DRAGON** (arXiv: 2604.25231, April 29, 2026) evaluates whether vision-language models can ground their reasoning in specific diagram regions rather than arriving at correct answers through shortcuts. The benchmark comprises 11,664 annotated question instances drawn from six existing diagram QA datasets, with a 2,445-instance human-verified test set. Models must produce bounding box predictions identifying the visual evidence regions — answer-bearing components, labels, legends, axes, connectors, and supporting structures — that justify their answers. Eight recent VLMs are evaluated.

## Benchmarks / Datasets
- 11,664 annotated question instances from 6 diagram QA datasets
- 2,445-instance human-verified test set
- 8 recent VLMs evaluated
- Evidence region types: answer-bearing components / labels / legends / axes / connectors / supporting structures
- Bounding box prediction as the grounding evaluation mechanism

## Key Results

| Evaluation Dimension | Key Finding |
|---|---|
| Answer accuracy vs. evidence grounding | Significant gap — correct answers do not guarantee correct grounding |
| Shortcut reasoning detection | Models frequently arrive at correct answers via spurious correlations |
| Grounding across evidence types | Consistent failure across all six evidence region types |
| Interpretability reliability | All 8 VLMs show grounding gaps relative to answer accuracy |

- **Achieving correct answers on diagram QA tasks does not guarantee that models ground reasoning in the appropriate diagram regions — high accuracy masks fundamentally unreliable reasoning**
- Models frequently exploit spurious correlations between question phrasing and answer patterns rather than reading the diagram's visual evidence
- The gap between answer accuracy and grounding accuracy is consistent across all 8 tested VLMs and all six evidence region types
- DRAGON provides the first framework for jointly evaluating diagram QA accuracy and reasoning interpretability through visual evidence localisation

## Enterprise / Industry Relevance
Foxconn's technical workflows depend heavily on engineering diagrams — circuit schematics, process flow charts, quality control charts, assembly diagrams, and CAD documentation. DRAGON's finding that VLMs achieve correct answers on diagram tasks without genuinely reading the relevant diagram regions is a critical reliability warning for FoxBrain: a model answering a question about a circuit diagram correctly may be pattern-matching from training data rather than reading the actual schematic. Before deploying FoxBrain on any diagram-based engineering task, DRAGON-style grounding evaluation is essential to verify that the model is reasoning from the correct visual evidence rather than from shortcut patterns.
